# kimiflare → autopilot

**kimiflare has been renamed to autopilot.** Install the new package:

```sh
npm uninstall -g kimiflare
npm install -g autopilot-ai
autopilot
```

Your settings, sessions, memory and cost history carry over automatically.

This final `kimiflare` release only forwards the `kimiflare` command to `autopilot-ai` and prints the notice above. It will not receive further updates.

Project: https://github.com/directionally-local/autopilot
